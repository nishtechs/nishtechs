# 💫 About Me

## Hi, I'm Nishant Sharma 👋

I’m currently working at **Rajasthan Knowledge Corporation Limited (RKCL)** and enjoy building practical solutions combining software, electronics, and AI.

### What I’m interested in
I’m open to collaborating on:
- Mobile, desktop, and web applications
- Electronics and IoT projects
- Applied AI systems, autonomous agents, and local LLMs
- Research and development combining hardware and software

### Technologies and areas I work with
- **Programming:** Java, Kotlin, Python, Dart, C, C++, Embedded C, MicroPython
- **Mobile Development:** Android Native (Kotlin/Java), Flutter
- **Hardware & IoT:** Raspberry Pi, ESP8266, ESP32, Arduino, sensors, microcontrollers
- **AI & Automation:** Local LLMs, LangChain, LangGraph, CrewAI, n8n, ONNX Runtime

### Currently learning
- Data Structures & Algorithms (DSA)
- Low-Level Design (LLD) & High-Level Design (HLD)

### Fun facts
- I enjoy bringing ideas to life with both code and circuits.
- I’m curious about how connected edge devices can solve everyday physical problems.
- My project ideas often start with a line of code—or a breadboard and electronic components. ⚡
